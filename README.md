# hs-webview

Haskell bindings for the official [webview](https://github.com/webview/webview)
C API. The raw FFI layer is generated by
[hs-bindgen](https://github.com/well-typed/hs-bindgen) from the upstream C
headers; on top sits a small idiomatic layer that returns
`Either WebviewError ()` and accepts `Text` for all string parameters.

## Prerequisites

- A working Nix installation (with flakes enabled). All other toolchain pieces
  — GHC, the C++ compiler, `hs-bindgen-cli`, GTK/WebKit on Linux, Cocoa/WebKit
  frameworks on macOS — are provided by the flake.
- The upstream `webview` C sources are vendored into `cbits/` from a pinned
  flake input. `cbits/` itself is **not** tracked in git: it is populated by
  the Nix build and by the dev shell.

## Quick start

```bash
cd hs-webview
nix develop
cabal run demo
```

`cabal run demo` opens a WebView window that talks to an embedded Scotty
server on `localhost:3737`.

A minimal usage looks like this:

```haskell
import WebView

main :: IO ()
main = withWebView False $ \wv -> do
  _ <- setTitle wv "hello"
  _ <- setSize wv 800 600 HintNone
  _ <- navigate wv "https://example.com"
  _ <- run wv
  pure ()
```

Every call returns `IO (Either WebviewError ())`. The example discards the
results for brevity; production code should inspect them.

## Module structure

| Module | Status | Purpose |
|---|---|---|
| `WebView` | hand-written | Idiomatic API: `Text` inputs, `Either WebviewError` outputs |
| `WebView.Error` | hand-written | `WebviewError` ADT |
| `WebView.Extras` | hand-written | `enableReloadShortcuts` (Cmd/Ctrl+R, F5) |
| `WebView.Internal` | hand-written | `WebView` handle, `unsafeFromRaw`/`toRaw` for power users |
| `WebView.Raw` | **generated** | Types, enums, pattern synonyms, `Storable` instances |
| `WebView.Raw.Safe` | **generated** | All 17 C calls as `foreign import ccall safe` |
| `WebView.Raw.Unsafe` | **generated** | All 17 C calls as `foreign import ccall unsafe` |

The generated modules are checked into git so consumers do not need
`libclang` or `hs-bindgen` to build. The `regen-bindings` app below
regenerates them from `cbits/include/webview/*.h`.

## Maintenance workflows

### Refreshing the vendored C sources

```bash
nix run .#sync-webview
```

Run this after `nix flake update webview` (or whenever the upstream `webview`
input changes). The dev shell also runs it automatically when `cbits/` is
empty.

### Regenerating the Haskell bindings

```bash
nix run .#regen-bindings
```

Run this after the C sources change in a way that affects the public API
(new/removed functions, changed enum values, struct layout differences).
Review the diff in `src/WebView/Raw*` before committing — and remember that
the hand-written layer in `WebView.hs` may need follow-up edits if signatures
moved.

### Verifying that bindings match the C headers

```bash
nix run .#check-bindings
```

Re-runs `regen-bindings` into a temp directory and diffs against the
committed `src/WebView/Raw*`. Useful as a CI gate: catches the case where
someone bumped the `webview` input but forgot to regenerate. Fails fast if
`cbits/` is empty.
