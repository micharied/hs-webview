## [Unreleased]

## [0.2.0.0] - 2026-06-02

### Changed

- **Breaking:** raw FFI bindings are now generated by
  [hs-bindgen](https://github.com/well-typed/hs-bindgen) and live in
  `WebView.Raw`, `WebView.Raw.Safe`, and `WebView.Raw.Unsafe`. The
  hand-written FFI in `WebView` and `WebView.Internal` has been removed.
- **Breaking:** every C call now returns `IO (Either WebviewError ())` instead
  of `IO ()`. Errors that were previously silently dropped surface explicitly.
- **Breaking:** all string parameters now take `Data.Text.Text` instead of
  `String`.
- **Breaking:** `WebView` is now a type alias for the generated `Webview_t`
  newtype rather than a hand-written one. The `Internal` module exports
  `unsafeFromRaw` / `toRaw` for power users.
- New `text` and `hs-bindgen-runtime` library dependencies.

### Added

- Full coverage of the upstream C API: `dispatch`, `getWindow`,
  `getNativeHandle`, `bind`, `unbind`, `webviewReturn`, `initJs`, `version`.
- `WebView.Error` module with the `WebviewError` ADT.
- `nix run .#regen-bindings` to refresh the generated `WebView.Raw*` modules
  from the vendored C headers.

## [0.1.1.0] - 2025-12-18

### Added

- Added a macOS Edit menu so standard copy/cut/paste/select-all shortcuts work
  in the bundled webview (plus undo/redo).
- Add reload helper and optional reload shortcuts (Cmd/Ctrl+R, F5).

## [0.1.0.0] - 2025-12-18

### Added

- Initial release of the `hs-webview` library providing minimal Haskell bindings
  to the upstream webview C API.
- Demo executable showcasing window creation and inline HTML rendering.
- Nix flake workflow to vendor the required C sources and provide reproducible
  builds across macOS and Linux.
